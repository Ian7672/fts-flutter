# fts – FadeTail UI

FadeTail is a Flutter application designed to help batch-normalize the ending portions of audio files.

## Question Mark Help Button

* The `?` icon on the AppBar opens a contextual help dialog that explains the technical function of each menu.
* All dialog text uses the app’s localization system, so it automatically follows the language selected by the user.
* The explanations cover: the Settings card, Advanced Settings, processing buttons, as well as the Theme, Language, Donation, and Credits sections in the side menu.

### How to Use

1. Run the application as usual and open the main FadeTail page.
2. Tap the `?` icon in the top-right corner whenever you need to understand the meaning of a specific control.
3. Read the per-section summary, then close the dialog with the *Close* button to return to work.
4. Change the language via the side menu if you want to view the explanations in another language.

This help dialog is read-only, making it safe to open at any time without interrupting any ongoing rendering processes.
